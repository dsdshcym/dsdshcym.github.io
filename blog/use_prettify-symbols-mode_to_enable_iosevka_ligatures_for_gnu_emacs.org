Recently, I switched back to GNU Emacs from emacs-mac-port[fn:1] for better performance. And there are 3 things that are missing from GNU Emacs but are supported by emacs-mac-port:

1. Font Ligatures
2. Emoji support
3. org-protocol://, mailto:// link handling

This post is a summary for the way I used to enable font ligatures for GNU Emacs, based on the [[https://gist.github.com/mrkgnao/49c7480e1df42405a36b7ab09fe87f3d][scripts]][fn:2] provided by @mrkgnao.

1. Install haskell if you haven't done it.

#+begin_src awk
brew cask install haskell-platform
#+end_src
2. Run haskell repl

#+begin_src awk
ghci
#+end_src
3. Generate parameters.toml and prettify-symbols-alist for latter Emacs configurations

#+begin_src awk
:load IosevkaConfigGen
toToml
toElisp
#+end_src
4. Get/Clone Iosevka[fn:3] source code
5. Append the contents in parameters.toml to Iosevka/parameters.toml
6. Install Iosevka's dependencies

#+begin_src awk
brew install nodejs ttfautohint otfcc-mac64
#+end_src
7. Build custom Iosevka

#+begin_src awk
npm install
make custom-config
make custom
#+end_src
8. Set prettify-symbols-alist in your Emacs init files
9. Enable prettify-symbols-mode

#+begin_src emacslisp
(setq prettify-symbols-unprettify-at-point t)
(global-prettify-symbols-mode +1)
#+end_src
