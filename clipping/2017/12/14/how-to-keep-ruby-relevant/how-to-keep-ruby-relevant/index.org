#+TITLE: How to keep Ruby Relevant?

- How to keep Ruby Relevant?

  1. Talk about Ruby More
  2. Learn new ideas
  3. Help maintain abandoned libraries
  4. Build new libraries
  5. Build new products with Ruby
  6. Teach people Ruby
